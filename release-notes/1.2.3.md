## Clippy v1.2.3

Apple Silicon build (`arm64`), requiring macOS 13 or later.

### Launch regression rollback
- Reverted the macOS app-bundle signing and launch metadata changes introduced in v1.2.2 to match the packaging used by v1.2.1, which launched successfully on the user's Mac.
- The hotkey implementation is unchanged from v1.2.1/v1.2.2. This release is a packaging rollback to restore app launch while the macOS permission/signing issue is investigated separately.
