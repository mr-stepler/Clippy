## Clippy v1.2.0

Apple Silicon build (`arm64`), requiring macOS 13 or later.

### New
- Added a dedicated **Links** filter.
- Search now matches a link's URL and domain, as well as its fetched page title when opt-in link previews are enabled.
- Link previews use the largest icon declared by the site and render crisply on Retina displays.

### Improvements and fixes
- Fixed a macOS keyboard-listener crash triggered by Caps Lock on recent macOS versions.
- Restored the `copied!` confirmation and made button tooltips compact and consistent with the notification styling.
- Selecting a history item still only copies it to the clipboard; Clippy does not paste automatically.

### Source files
- `app.py`: link filtering/search, favicon rendering, keyboard-listener safeguards, and tooltip/notification styling.
- `README.md`: updated feature documentation.
