## Clippy v1.2.4

Apple Silicon build (`arm64`), requiring macOS 13 or later.

### Fixes
- Fixed macOS hotkey event suppression by preserving the native virtual key code before pynput canonicalizes character keys. The configured full chord opens Clippy without leaking the trigger key to the foreground app; modifier-only presses and unrelated keys remain untouched.
- Added a stable macOS bundle identifier so privacy permissions can be associated with the Clippy app bundle across launches.
- Repaired the macOS uninstaller: it no longer matches and terminates its own shell process, removes the actual case-sensitive lock file and Qt preferences, handles standard app locations, requests administrator authorization when needed, and reports failed removals.
- Accessibility and Input Monitoring permissions remain managed by macOS and must be removed manually in System Settings if desired.
