## Clippy v1.2.1

Apple Silicon build (`arm64`), requiring macOS 13 or later.

### macOS hotkey fixes
- Clippy now consumes only its configured global shortcut, so `Cmd + Shift + V` no longer leaks to the foreground app and triggers the macOS unassigned-shortcut sound.
- The keyboard event tap is re-enabled if macOS disables it, and the listener restarts automatically if it exits unexpectedly.
- Opening Clippy from its global shortcut now explicitly activates the accessory app and restores a minimized window.

Other keystrokes and synthetic keyboard events continue to pass through normally.
