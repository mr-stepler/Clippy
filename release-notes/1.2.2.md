## Clippy v1.2.2

Apple Silicon build (`arm64`), requiring macOS 13 or later.

### macOS permissions and app identity
- Restored Clippy's stable macOS bundle identifier (`com.mrstepler.clippy`) and ad-hoc bundle signing so macOS can associate Accessibility and Input Monitoring permissions with the installed app.
- Set the bundle's minimum macOS version to 13, matching the Qt/PySide6 runtime.

After installing this update, if the hotkey still does not open the window, remove the old Clippy entry and add `/Applications/Clippy.app` again under both **Accessibility** and **Input Monitoring** in System Settings → Privacy & Security.
